A personal usage profile page in the DSH sidebar, folded from this machine's own session logs through ctx.sessionQuery. One range switch in the header (7 / 30 / 90 days or all time) drives the page: five headline numbers (tokens in that range with a trend line and the change against the previous period, today's tokens, longest task, longest and current active-day streaks), a 12-month activity grid in daily / weekly / running-total views, a stacked model-family chart for the same range by day, week or month (version and tier stay apart, and vendor-specific ids collapse correctly), a Cache Lens that shows the cache hit rate and splits tokens into cache hits, uncached input and output with a zoom into the uncached part, and a per-provider split with each route's own hit rate. The selected range exports as CSV or JSON. The only outbound request is a six-hourly read of this package's own version from npm for the in-panel update button - no telemetry, no credentials, nothing uploaded.
