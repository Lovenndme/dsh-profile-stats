A personal usage profile page in the DSH sidebar: five headline numbers (cumulative tokens with a recent-days sparkline, today's tokens, longest task, longest and current active-day streaks), a 12-month activity heatmap with daily / weekly / cumulative scopes, a stacked model-family chart with its own day / week / month window (version and tier stay apart, and vendor-specific ids collapse correctly), a Cache Lens that shows the cache hit rate and splits every token into cache hits, uncached input and output, with a zoom into the uncached part, and a per-provider split for today or all time. Everything is folded from this machine's own session logs through ctx.sessionQuery. The only outbound request is a six-hourly read of this package's own version from the npm registry, used by the in-panel update button - no telemetry, no credentials, nothing uploaded.
