A personal usage profile page in the DSH sidebar. Five headline numbers (cumulative tokens, today's tokens, longest task, longest and current active-day streaks), a 12-month activity heatmap with daily / weekly / cumulative scopes, a Cache Lens that splits every token into cache hits, uncached input and output as a segmented bar (with a zoom into the uncached split), a stacked bar chart of tokens over time grouped by model family (version plus tier, so vendor-specific ids and unversioned aliases collapse correctly), and a per-provider split for today or all time. A page-level range (all / today / 7 days / 30 days) drives the token figures. Everything is folded from this machine's own session logs through ctx.sessionQuery. The only outbound request is a six-hourly read of this package's own version from the npm registry, used by the in-panel update button — no telemetry, no credentials, nothing uploaded.
