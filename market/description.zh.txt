DSH 侧栏的个人用量主页，数据全部由本机会话日志经 ctx.sessionQuery 折叠而来。包括五个核心数字（用量带小趋势与环比、花费、最长任务用时、连续活跃天数及最长纪录、今日缓存命中率）、近 12 个月活动图（每天 / 每周 / 累计三档）、按日 / 周 / 月分组的模型家族图（堆叠柱看用量、饼图看占比，版本与档位分开，不同供应商写法会正确归并）、按系统提示词 / 工具定义 / 用户消息 / 注入内容 / 技能注入 / 工具调用 / 模型思考 / 模型回复拆分的 Token 统计环形图、按工作目录拆分用量与花费并标出子代理占比的项目，以及带各自命中率与花费的供应商分类。页头的时间范围开关（本日 / 本周 / 本月 / 累计 / 自定义日期）驱动用量与花费数字、Token 统计、项目和供应商分类，所选范围可导出 CSV 或 JSON。花费按内置的官方价折算（直连 DeepSeek 分高峰、空闲时段），每家供应商可设成官方价、倍率、包月或不计入，设置只存在本机。唯一的外发请求是每 6 小时读一次本包在 npm 上的版本号（供面板内的更新按钮使用），不上报数据、不碰凭据。
